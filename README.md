# تعلیمِ نو اے آئی (Taleem-e-Nau AI) 🚀
### کراچی بورڈ تعلیمی معاون اور عالمی زبان سیکھنے کا مربوط پلیٹ فارم

تعلیمِ نو اے آئی ایک پریمیم، جدید اور انتہائی خوبصورت سنگل پیج ویب ایپلی کیشن (SPA) ہے جسے مصنوعی ذہانت (AI) کے اصولوں پر مبنی تعلیمی عمل کو آسان اور دلکش بنانے کے لیے ڈیزائن کیا گیا ہے۔

---

## 🌟 اہم خصوصیات (Key Features)

### 1۔ کراچی بورڈ تعلیمی معاون (Karachi Board Academic Assistant)
* **تمام مضامین کا احاطہ:** جماعت ۵ سے ۱۲ کے لیے ریاضی، سائنس، فزکس، کیمسٹری، بیالوجی، کمپیوٹر سائنس، اور اردو/انگریزی کے تمام سوالات کا حل۔
* **ان پٹ کے کثیر طریقے:** ٹیکسٹ ٹائپنگ، امیج اپ لوڈ (ہاتھ سے لکھے ہوئے نوٹس، درسی کتب کے صفحات)، اور پی ڈی ایف دستاویزات کا تجزیہ۔
* **اے آئی شفیق استاد کی شخصیت:** بالکل سادہ، آسان اور عام فہم اردو میں مرحلہ وار تشریحات۔
* **فیڈ بیک اور ریٹنگ سسٹم:** طالب علم کی فہم کے مطابق تشریح کی کوالٹی جانچنے کا نظام۔

### 2۔ عالمی زبان سیکھنے کا ماڈیول (Global Language Learning Module)
* **کثیر لسانی تدریس:** اردو، انگریزی، عربی، چینی، فرانسیسی اور ہسپانوی زبانیں سیکھنے کی سہولت۔
* **۴ تعلیمی درجات:** بنیادی (Basic)، درمیانہ (Normal)، ماہرانہ (Expert)، اور پیشہ ورانہ (Professional)۔
* **کامیابی کا نظام (Progression System):** ہر مرحلے کے بعد ۲۰ سوالات کا انٹرایکٹو کوئز۔ کم از کم ۸۰٪ نمبر حاصل کرنے پر ہی اگلا مرحلہ ان لاک ہوتا ہے۔
* **اصلاحی طریقہ کار (Remediation Path):** کوئز پاس نہ کرنے پر طالب علم کی کمزوریوں کے مطابق مخصوص اسباق اور مشقوں کا دوبارہ جائزہ۔

## 🛠️ لوکل ہوسٹ پر چلانے کا طریقہ (How to Run Locally)

اپنے کمپیوٹر پر اس ایپ کو چلانے کے لیے درج ذیل مراحل پر عمل کریں:

1. **انحصار (Dependencies) انسٹال کریں:**
   ٹرمینل میں یہ کمانڈ چلائیں:
   ```bash
   npm install
   ```

2. **ڈویلپمنٹ سرور شروع کریں:**
   ایپ کو لوکل ہوسٹ پر چلانے کے لیے یہ کمانڈ دیں:
   ```bash
   npm run dev
   ```
   اس کے بعد اپنے براؤزر میں ٹرمینل میں دیے گئے لنک (عام طور پر `http://localhost:5173`) کو اوپن کریں۔

## 🌐 گٹ ہب پر لائیو اپ لوڈ کرنے کا طریقہ (How to Host on GitHub Pages)

اس پراجیکٹ کو گٹ ہب پر ہوسٹ کرنے اور دوستوں کے ساتھ شیئر کرنے کے لیے درج ذیل اقدامات کریں:

1. **گٹ ہب پر ایک نیا ریپوزٹری (Repository) بنائیں:**
   لاگ ان کریں اور ایک نیا پراجیکٹ بنائیں۔ اس کا نام `Taleem-e-Nau-AI` رکھیں۔

2. **اپنے کمپیوٹر پر گٹ انیشیئلائز کریں:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Taleem-e-Nau AI"
   ```

3. **گٹ ہب ریپوزٹری سے لنک کریں اور پش کریں:**
   *(اپنے ریپوزٹری کا یو آر ایل درج کریں)*
   ```bash
   git remote add origin <your-github-repo-url>
   git branch -M main
   git push -u origin main
   ```

4. **GitHub Pages آن کریں:**
   - گٹ ہب پر اپنے ریپوزٹری کے **Settings** پیج پر جائیں۔
   - بائیں جانب مینو سے **Pages** پر کلک کریں۔
   - **Build and deployment** کے تحت، **Source** کو "Deploy from a branch" رکھیں اور برانچ کو **main** اور فولڈر کو `/ (root)` منتخب کر کے **Save** کر دیں۔
   - کچھ ہی دیر میں آپ کا لائیو یو آر ایل تیار ہو جائے گا جسے آپ براہ راست موبائل یا کمپیوٹر پر چلا سکتے ہیں!
